## 🚀 Deploy (GitHub + Vercel)

### Push to GitHub

```bash
git remote add origin https://github.com/Eliyas47/Eliyas-Siyum.git
git branch -M main
git push -u origin main
```

If the remote already exists, update it instead:

```bash
git remote set-url origin https://github.com/Eliyas47/Eliyas-Siyum.git
git push -u origin main
```

### Deploy on Vercel

1. Go to [Vercel](https://vercel.com/) and sign in with GitHub.
2. Select **Add New Project** and import `Eliyas47/Eliyas-Siyum`.
3. Select **Vite** if your project uses Vite.
4. Configure the build command as `npm run build` and output directory as `dist`, if applicable.
5. Click **Deploy**.
6. Verify that the deployed website uses `https://eliyas-siyum.vercel.app`.

